# Diwali Afterglow

Static site. Upload `index.html`, `style.css`, `script.js` to a GitHub repo, then Settings > Pages > Deploy from branch (main, root).

RSVPs: open `script.js` and set `WHATSAPP` (digits with country code, e.g. `919876543210`) or `RSVP_EMAIL`. Guests tap Lessgoo, WhatsApp/email opens pre-filled, they hit send. Leave both empty and it only celebrates.
